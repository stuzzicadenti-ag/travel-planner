# TravelPlanner

AI-powered travel diary and trip planner. Plan personalized itineraries, document your journeys with photos and notes, and share your adventures with a growing community of travelers.

## Features

- **AI Trip Suggestions** - Personalized recommendations for monuments, hidden gems, and local favorites
- **Interactive Map** - Visualize itineraries with Google Maps integration (planned)
- **Photo Diary** - Upload photos with automatic location metadata
- **Trip Timeline** - Visual day-by-day flow of activities with descriptions
- **Travel Stats** - Track countries visited, kilometers traveled, days on the road
- **Community Sharing** - Share trips publicly or privately, follow other travelers
- **Login/Register** - Account system with email and password authentication
- **Responsive Design** - Mobile-first, works on all screen sizes

## Tech Stack

- HTML5, semantic markup with full SEO (Open Graph, Twitter Cards, JSON-LD structured data)
- CSS3, custom properties, flexbox/grid, soft shadows, gradient accents
- Vanilla JavaScript (no frameworks, no external dependencies)
- GitHub Pages for hosting

# TravelPlanner

AI-powered travel diary and trip planner — plan, explore, and remember your adventures.

## Overview

TravelPlanner is an interactive travel companion that helps you discover destinations, build AI-generated itineraries, document your journeys with photos and notes, and share your travel stories with a community of explorers.

## Features

- **AI Trip Suggestions** — Personalized day-by-day itineraries generated by AI
- **Interactive Map** — Visualize routes, distances, and nearby attractions
- **Photo Diary** — Upload photos with automatic location metadata
- **Trip Timeline** — Visual flow of daily activities with timestamps
- **Travel Stats** — Track countries visited, kilometers traveled
- **Community Sharing** — Publish trips or follow other travelers

## Tech Stack

- HTML5 + CSS3 (vanilla, no frameworks)
- GitHub Pages (static hosting)
- GitHub Actions CI/CD

## Deployment

| Branch | Environment | URL |
|--------|------------|-----|
| `dev` | Preview | Auto-deployed on push |
| `main` | Production | [stuzzicadenti-ag.github.io/travel-planner](https://stuzzicadenti-ag.github.io/travel-planner/) |

## CI/CD Pipeline

```
Push to dev  ──→ Lint ──→ Deploy Preview
Push to main ──→ Lint ──→ Deploy Production
```

- **Lint**: HTML validation (tidy) + secret detection
- **Deploy**: GitHub Pages via Actions artifact upload
